Introduction and idea :  
TaskFlow is a web-based Project and Task Management System designed to help teams 
organize their work, manage projects, assign tasks, and track progress
efficiently through a centralized platform.
The system aims to simplify team collaboration and improve productivity by providing essential project
management tools, including task assignment,
status tracking, project progress monitoring, comments, and notifications.
TaskFlow is being developed using ASP.NET Core MVC and Entity Framework Core,
with SQL Server as its database management system. 
The project focuses on applying Full Stack .NET development concepts, database design, 
object-oriented programming, and software architecture principles in a practical real-world application.
